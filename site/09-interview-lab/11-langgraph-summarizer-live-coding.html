Live Coding: A Working LangGraph Summarizer Agent

19 min listen · How to talk your way through the live-coding question 'write a working LangGraph summarizer agent': clarify first, then build a map-reduce graph on a whiteboard — state with reducers, Send fan-out over chunks, a bounded collapse loop, a final summary, a checkpointer that resumes only the failed branch, split error handling and three-channel streaming.

Facts verified: 2026-09-25 — code below was executed end to end in a clean venv (Python 3.11.15) with langgraph 1.2.12, langgraph-checkpoint 4.2.0, langchain-core 1.6.5, langchain-text-splitters 1.1.2 (real-model swap path checked for import/instantiation with langchain 1.4.2 + langchain-anthropic 1.7.4 / langchain-openai 1.6.6; no live API call was made).

One-sentence thesis

"Write a working LangGraph summarizer" is graded on design narration, not typing: clarify, then build a map-reduce graph whose state survives parallel writes (reducers), whose fan-out is dynamic (Send), whose collapse loop is bounded, whose failures are split into retry-able vs disclose-able, whose runs are resumable (checkpointer + pending writes), and whose progress is streamed.

Minute-zero clarifying questions (say them out loud)

  1. Input size range? (fits in context → just stuff it; say so.)
  2. Output shape? (prose / bullets / structured with section citations)
  3. Latency budget? (interactive → parallel map-reduce + streaming; batch → throughput, queue)
  4. Failure tolerance? (partial summary with disclosed gaps vs fail the whole doc)
  5. Progress visibility needed? (streaming modes)

The complete, tested code — summarizer_agent.py

"""Map-reduce summarizer agent in LangGraph.

split -> (Send fan-out) summarize_chunk x N -> collect -> [collapse loop] -> final_summary
Runs offline with a deterministic fake chat model; swap in a real model via get_model().
"""
from __future__ import annotations

import operator
import os
from typing import Annotated, Any, Iterator, Literal, Optional

from typing_extensions import TypedDict

from langchain_core.callbacks import CallbackManagerForLLMRun
from langchain_core.language_models import BaseChatModel
from langchain_core.messages import AIMessage, AIMessageChunk, BaseMessage
from langchain_core.outputs import ChatGeneration, ChatGenerationChunk, ChatResult
from langchain_core.prompts import ChatPromptTemplate
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langgraph.checkpoint.memory import InMemorySaver
from langgraph.config import get_stream_writer
from langgraph.graph import END, START, StateGraph
from langgraph.types import RetryPolicy, Send

# ---------------------------------------------------------------------------
# 1. Model: deterministic fake for tests/CI, real model in production
# ---------------------------------------------------------------------------


class FakeSummarizer(BaseChatModel):
    """Deterministic 'summarizer' for offline tests: for each line after the '---'
    marker it keeps the first `words_per_line` words, capped at `max_words` total.
    Supports token streaming. Failure injection:
      - `fail_first_n`: first N calls raise ConnectionError (transient -> retried)
      - a passage containing 'BLOCKED' raises ValueError (permanent, e.g. content filter)
      - `outage_marker`: any passage containing this string raises ConnectionError
        (a provider outage hitting one branch, for the resume demo)"""

    words_per_line: int = 6
    max_words: int = 18
    fail_first_n: int = 0
    outage_marker: Optional[str] = None
    calls: int = 0

    @property
    def _llm_type(self) -> str:
        return "fake-summarizer"

    def _summarize(self, messages: list[BaseMessage]) -> str:
        self.calls += 1
        text = str(messages[-1].content).split("---", 1)[-1]
        if self.calls <= self.fail_first_n or (self.outage_marker and self.outage_marker in text):
            raise ConnectionError(f"simulated provider 503 (call {self.calls})")
        if "BLOCKED" in text:
            raise ValueError("simulated content-filter rejection")
        lines = [" ".join(l.split()[: self.words_per_line]) for l in text.splitlines() if l.strip()]
        return " ".join(" | ".join(lines).split()[: self.max_words])

    def _generate(self, messages, stop=None, run_manager=None, **kwargs) -> ChatResult:
        return ChatResult(generations=[ChatGeneration(message=AIMessage(content=self._summarize(messages)))])

    def _stream(
        self,
        messages: list[BaseMessage],
        stop: Optional[list[str]] = None,
        run_manager: Optional[CallbackManagerForLLMRun] = None,
        **kwargs: Any,
    ) -> Iterator[ChatGenerationChunk]:
        for i, word in enumerate(self._summarize(messages).split(" ")):
            chunk = ChatGenerationChunk(message=AIMessageChunk(content=("" if i == 0 else " ") + word))
            if run_manager:
                run_manager.on_llm_new_token(chunk.text, chunk=chunk)
            yield chunk


def get_model() -> BaseChatModel:
    """Swap point. Set SUMMARIZER_MODEL (e.g. 'anthropic:<model-id>' or 'openai:<model-id>')
    and `pip install langchain langchain-anthropic` (or langchain-openai) to use a real model."""
    spec = os.getenv("SUMMARIZER_MODEL")
    if spec:
        from langchain.chat_models import init_chat_model  # requires `pip install langchain`

        return init_chat_model(spec, temperature=0, max_retries=0)  # retries handled by the graph
    return FakeSummarizer(fail_first_n=int(os.getenv("FAKE_FAIL_FIRST_N", "0")))


llm = get_model()

MAP_PROMPT = ChatPromptTemplate.from_messages(
    [("system", "Summarize the passage in 2-3 factual sentences. Keep numbers, names and dates exactly."),
     ("human", "Passage:\n---\n{text}")]
)
REDUCE_PROMPT = ChatPromptTemplate.from_messages(
    [("system", "Merge these partial summaries into one coherent summary. Do not add facts."),
     ("human", "Partial summaries:\n---\n{text}")]
)

# ---------------------------------------------------------------------------
# 2. Budgets
# ---------------------------------------------------------------------------
CHUNK_SIZE = int(os.getenv("CHUNK_SIZE", "400"))   # characters per chunk (use tokens in prod)
TOKEN_MAX = int(os.getenv("TOKEN_MAX", "30"))      # max tokens the final reduce call may see
MAX_COLLAPSE_ROUNDS = 5                            # hard stop for the collapse loop


def count_tokens(texts: list[str]) -> int:
    """Cheap approximation (~1 token per word). In prod use llm.get_num_tokens or the provider tokenizer."""
    return sum(len(t.split()) for t in texts)


def group_by_budget(texts: list[str], budget: int) -> list[list[str]]:
    groups, current = [], []
    for t in texts:
        if current and count_tokens(current + [t]) > budget:
            groups.append(current)
            current = []
        current.append(t)
    if current:
        groups.append(current)
    return groups


# ---------------------------------------------------------------------------
# 3. State
# ---------------------------------------------------------------------------


class OverallState(TypedDict, total=False):
    document: str
    chunks: list[str]
    # Parallel Send branches all write here -> needs an append reducer.
    summaries: Annotated[list[dict], operator.add]
    failures: Annotated[list[dict], operator.add]
    # Written by one node at a time -> default "replace" semantics.
    collapsed: list[str]
    collapse_rounds: int
    final_summary: str


class ChunkState(TypedDict):
    """Private per-branch payload carried by each Send."""
    index: int
    text: str


# ---------------------------------------------------------------------------
# 4. Nodes
# ---------------------------------------------------------------------------


def split(state: OverallState) -> dict:
    splitter = RecursiveCharacterTextSplitter(chunk_size=CHUNK_SIZE, chunk_overlap=40)
    chunks = splitter.split_text(state["document"])
    get_stream_writer()({"stage": "split", "chunks": len(chunks)})
    return {"chunks": chunks}


def fan_out(state: OverallState) -> list[Send]:
    # One Send per chunk -> N parallel summarize_chunk tasks in the next super-step.
    return [Send("summarize_chunk", {"index": i, "text": c}) for i, c in enumerate(state["chunks"])]


def summarize_chunk(state: ChunkState) -> dict:
    try:
        summary = (MAP_PROMPT | llm).invoke({"text": state["text"]}).content
    except ValueError as e:
        # PERMANENT error (content filter, bad input): retrying won't help. Degrade
        # gracefully: record it, emit a visible placeholder, let the other chunks finish.
        get_stream_writer()({"stage": "map", "chunk": state["index"], "error": str(e)})
        return {"summaries": [{"index": state["index"], "summary": f"[section {state['index']} could not be summarized]"}],
                "failures": [{"index": state["index"], "error": str(e)}]}
    # TRANSIENT errors (ConnectionError, TimeoutError) are NOT caught here: they
    # propagate to the node's RetryPolicy (exponential backoff + jitter).
    get_stream_writer()({"stage": "map", "chunk": state["index"]})
    return {"summaries": [{"index": state["index"], "summary": summary}]}


def collect(state: OverallState) -> dict:
    # Parallel branches finish in any order: restore document order by index.
    ordered = [s["summary"] for s in sorted(state["summaries"], key=lambda s: s["index"])]
    return {"collapsed": ordered, "collapse_rounds": 0}


def should_collapse(state: OverallState) -> Literal["collapse", "final_summary"]:
    too_big = count_tokens(state["collapsed"]) > TOKEN_MAX
    if too_big and state.get("collapse_rounds", 0) < MAX_COLLAPSE_ROUNDS:
        return "collapse"
    return "final_summary"


def collapse(state: OverallState) -> dict:
    groups = group_by_budget(state["collapsed"], TOKEN_MAX)
    # batch() runs the group reductions concurrently; order of outputs matches inputs.
    outs = (REDUCE_PROMPT | llm).batch([{"text": "\n".join(g)} for g in groups])
    rounds = state.get("collapse_rounds", 0) + 1
    get_stream_writer()({"stage": "collapse", "round": rounds, "groups": len(groups)})
    return {"collapsed": [o.content for o in outs], "collapse_rounds": rounds}


def final_summary(state: OverallState) -> dict:
    msg = (REDUCE_PROMPT | llm).invoke({"text": "\n".join(state["collapsed"])})
    summary = msg.content
    if state.get("failures"):
        # Never silently drop coverage: say which sections are missing (audit-friendly).
        missing = sorted(f["index"] for f in state["failures"])
        summary += f"\n\n[Coverage note: chunks {missing} could not be summarized.]"
    return {"final_summary": summary}


# ---------------------------------------------------------------------------
# 5. Graph
# ---------------------------------------------------------------------------
retry = RetryPolicy(max_attempts=3, initial_interval=0.1, backoff_factor=2.0,
                    retry_on=(ConnectionError, TimeoutError))

builder = StateGraph(OverallState)
builder.add_node("split", split)
builder.add_node("summarize_chunk", summarize_chunk, retry_policy=retry)
builder.add_node("collect", collect)
builder.add_node("collapse", collapse, retry_policy=retry)
builder.add_node("final_summary", final_summary, retry_policy=retry)

builder.add_edge(START, "split")
builder.add_conditional_edges("split", fan_out, ["summarize_chunk"])
builder.add_edge("summarize_chunk", "collect")
builder.add_conditional_edges("collect", should_collapse, ["collapse", "final_summary"])
builder.add_conditional_edges("collapse", should_collapse, ["collapse", "final_summary"])
builder.add_edge("final_summary", END)

graph = builder.compile(checkpointer=InMemorySaver())


# ---------------------------------------------------------------------------
# 6. Demo
# ---------------------------------------------------------------------------
SAMPLE = "\n\n".join(
    f"Section {i}. The quarterly credit risk report notes that exposure in segment {i} "
    f"changed by {i * 3} percent, driven by refinancing activity and updated collateral "
    f"valuations. Analysts flagged {i} accounts for manual review before the audit deadline. "
    f"No policy exceptions were recorded for segment {i} in this period."
    for i in range(1, 9)
)

def demo_stream() -> None:
    config = {"configurable": {"thread_id": "doc-42"}, "max_concurrency": 4}
    print("=== 1. streaming: progress (updates + custom) and final tokens (messages) ===")
    for mode, chunk in graph.stream({"document": SAMPLE}, config,
                                    stream_mode=["updates", "custom", "messages"]):
        if mode == "custom":
            print("progress:", chunk)
        elif mode == "updates":
            print("node done:", list(chunk.keys()))
        elif mode == "messages":
            token, meta = chunk
            if meta.get("langgraph_node") == "final_summary":
                print("token:", repr(token.content))

    values = graph.get_state(config).values
    print("\nchunks:", len(values["chunks"]), "| map summaries:", len(values["summaries"]),
          "| collapse rounds:", values["collapse_rounds"], "| failures:", values.get("failures", []))
    print("FINAL:", values["final_summary"])
    print("checkpoints for thread doc-42:", len(list(graph.get_state_history(config))))
    print("model calls:", getattr(llm, "calls", "n/a"))


def demo_permanent_failure() -> None:
    print("\n=== 2. permanent failure on one chunk -> graceful degradation ===")
    doc = SAMPLE.replace("Section 3.", "Section 3. BLOCKED")
    out = graph.invoke({"document": doc}, {"configurable": {"thread_id": "doc-43"}})
    print("failures:", out["failures"])
    print("FINAL:", out["final_summary"])


def demo_resume_after_outage() -> None:
    print("\n=== 3. provider outage mid-run -> resume from checkpoint ===")
    if not isinstance(llm, FakeSummarizer):
        return
    config = {"configurable": {"thread_id": "doc-44"}}
    llm.outage_marker = "Section 5."  # one branch keeps failing; retries exhausted -> run raises
    try:
        graph.invoke({"document": SAMPLE}, config)
    except ConnectionError as e:
        print("run failed:", e)
    snap = graph.get_state(config)
    print("checkpoint parked before:", snap.next)
    llm.outage_marker = None  # provider recovers
    before = llm.calls
    out = graph.invoke(None, config)  # None = resume this thread from its last checkpoint
    # Only the failed branch re-runs: the 7 successful map results were saved as
    # pending writes on the checkpoint. Extra calls = 1 map + collapse + final.
    print("resumed; extra model calls:", llm.calls - before)
    print("FINAL:", out["final_summary"])


if __name__ == "__main__":
    demo_stream()
    demo_permanent_failure()
    demo_resume_after_outage()

Reading the numbers: a full run is 8 map + 4 collapse (2 rounds x 2 groups) + 1 final = 13 calls. The resumed run after the outage made 6 calls = 1 map (only the failed branch) + 4 collapse + 1 final — the other 7 map results were kept as pending writes on the checkpoint. With FAKE_FAIL_FIRST_N=2 the full run makes 15 calls (2 retried by RetryPolicy).

(The fake "summarizer" just keeps the first words of each line — deterministic by design so tests are stable. With a real model the summaries are real prose.)

Design decisions worth narrating

Decision Why Trap it avoids
summaries: Annotated[list[dict], operator.add] Parallel Send branches write the same key in one super-step Without it: InvalidUpdateError: At key 'summaries': Can receive only one value per step (verified)
Each summary carries index; collect sorts Branches complete in provider order, not document order Summary that reorders sections / misattributes figures
ChunkState private schema for the desk Desk needs only index + text Bloated per-branch payloads & checkpoints
max_concurrency in run config Caps parallel model calls Rate-limit storms on 200-chunk documents
collapse_rounds cap (5) Reducer may not shrink single-item groups Unbounded loop — LangGraph's default recursion_limit is 10007 in 1.2.12 (verified by running a self-loop), far too high to protect a bill
RetryPolicy(retry_on=(ConnectionError, TimeoutError)) on model nodes; client max_retries=0 Retry in exactly ONE layer Multiplicative retries (client x node x scheduler)
Catch permanent errors (ValueError here) inside the desk, record in failures, placeholder summary Content-filter / garbled page won't fix itself Burning retries; silently dropping coverage
Coverage note in final_summary Regulated readers must know what's missing Confident summary of 90% of a document
Checkpointer + thread_id per document Resume only failed branches; audit via get_state_history Re-running (and re-paying for) the whole doc
Stream updates + custom + messages (filter langgraph_node == "final_summary") Progress bar + live typing of the final answer only Blank screen; 40 partial summaries flickering past

Newer options (present in langgraph 1.2.12, check your team's version): add_node(..., error_handler=...) (handler receives a NodeError with .node / .error), timeout= / TimeoutPolicy per node (async nodes only), StateGraph.set_node_defaults(retry_policy=..., error_handler=..., timeout=...), and the opt-in typed streaming format graph.stream(..., version="v2") (LangGraph 1.1+) which yields dicts {"type", "ns", "data"} and makes invoke return a GraphOutput with .value / .interrupts (both verified locally).

Map-reduce vs refine vs stuff

Strategy Calls / wall-clock Strength Weakness
Stuff (one call) 1 No drift, full cross-references Needs context headroom; pays full input every request; weaker recall of mid-document details
Map-reduce (this graph) N parallel + 1–2 reduce rounds ≈ a few call latencies Parallel, scales to any length, per-chunk failure isolation Chunks lose cross-references; summaries-of-summaries drift
Refine N sequential Narrative continuity Slow (N x latency), early content diluted, one failure blocks the chain

Scale: ~300 pages ≈ ~150k tokens → at 4k-token chunks ≈ 40 map calls; input cost ≈ the document once plus a small multiple for summaries.

Key terms

Term Meaning
StateGraph Graph builder over a typed state schema
Reducer (old, update) -> new per state key; operator.add appends lists
Send(node, arg) Dynamic fan-out: run node once per Send with a private input, in parallel, next super-step
Super-step One tick: all active nodes run in parallel, writes merged via reducers, checkpoint saved
Pending writes Results of successful tasks in a partly-failed super-step, stored so resume doesn't redo them
thread_id Key under which a run's checkpoints are stored; resume with invoke(None, config)
RetryPolicy Per-node retry: max_attempts, initial_interval, backoff_factor, max_interval, jitter, retry_on
get_stream_writer() Emit custom events from inside a node (stream_mode="custom")
stream_mode="messages" Token stream from model calls, with metadata incl. langgraph_node
Token max Budget the collapsed pile must fit under before the final call

5 interview questions with strong answers

Q1. Walk me through your summarizer design before you code. Clarify size, output, latency, failure tolerance. If it fits in context, one call. Otherwise map-reduce: split by tokens with overlap on section boundaries; fan out one Send per chunk with a private index+text payload; append reducer for partial summaries; collect sorts by index; bounded collapse loop while the pile exceeds a token budget; final node produces the output plus a coverage note; checkpointer, per-node retries, streaming.

Q2. Why does the partial-summaries key need a reducer? All map branches run in the same super-step and write the same key. With default replace semantics LangGraph raises InvalidUpdateError ("Can receive only one value per step"). Annotated[list, operator.add] concatenates the writes. Because append order is completion order, each item carries its chunk index and collect sorts.

Q3. One chunk out of 200 keeps failing. What happens? Classify it. Transient (timeouts, 429/503): the node RetryPolicy retries with backoff and jitter; the model client's own retries are off so retries don't multiply. If it still fails, the run errors but the checkpointer keeps the other 199 results as pending writes; invoke(None, same thread_id) re-runs only the failed branch (verified: 6 extra calls instead of 13). Permanent (content filter, garbage input): caught in the node, placeholder + failures entry, and the final summary discloses the gap.

Q4. How do you make sure the collapse loop terminates and doesn't degrade quality? Keep a round counter in state and route to the final node when it hits a cap; don't rely on recursion_limit (default 10007 in current Python LangGraph). Size chunks and token max so most docs need 0–1 collapse rounds, and instruct the reduce prompt to preserve figures, dates and caveats, because each round is lossy.

Q5. How would you test this and how would you verify faithfulness? Unit tests with a deterministic fake chat model that supports streaming and failure injection — prove retries, graceful degradation and resume without an API key. For quality: an LLM-as-judge groundedness check against source chunks on a representative sample, plus a deterministic check that every number in the summary appears in the source; track judge-human agreement (see episode 7).
