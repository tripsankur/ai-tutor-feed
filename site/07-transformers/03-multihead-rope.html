Multi-Head Attention, RoPE, Residuals, LayerNorm

17 min listen · The full transformer block as a building: a conveyor belt of tiles rising through identical floors, an attention room with many desks on the left, a feed-forward room on the right, leveling gates at every door, and clock dials that tell each tile where it sits — plus the modern variants every current open model uses: grouped-query attention, RMSNorm, pre-norm, and rotary positions.

Facts verified: 2026-09-25

One-sentence thesis

A modern transformer layer is attention plus plumbing — a residual stream that every sublayer reads from and adds to, pre-norm RMSNorm at each sublayer's input, multi-head attention with grouped K/V heads to shrink the KV cache, a gated (SwiGLU) feed-forward holding most parameters, and rotary position encoding applied to Q and K — and it's the plumbing, not attention alone, that makes 100+ layer models trainable and servable.

The mental image: the building

  • Shelf of tiles at ground level; a conveyor belt (residual stream) carries them up through identical floors (layers).
  • Left room on each floor = attention. Inside: many desks (heads), each with its own flag/label/bucket lenses.
  • Filing cabinets shared by groups of desks = GQA (one cabinet for all = MQA).
  • Right room = feed-forward (SwiGLU): each tile thinks alone; most of the parameters.
  • Leveling gate at each room's doorway = pre-norm RMSNorm; one final gate on the roof.
  • Rooms read a copy and add back to the belt → residual connection; the belt is a clean gradient highway.
  • Clock dials on flags and labels, rotated by position, many hands at different speeds = RoPE.

The block in code (Llama-style, simplified)

def block(x, pos):
    # pre-norm: normalize the input to each sublayer, never the residual stream itself
    h = x + attention(rms_norm(x), pos)     # residual add
    return h + swiglu_ffn(rms_norm(h))      # residual add

def rms_norm(x, g, eps=1e-6):
    return g * x / sqrt(mean(x**2, dim=-1) + eps)       # no mean subtraction (vs LayerNorm)

def swiglu_ffn(x):
    return W_down @ (silu(W_gate @ x) * (W_up @ x))     # gate acts as a per-element dimmer

# Original (post-norm, 2017):  x = LayerNorm(x + Sublayer(x))
# Modern (pre-norm):           x = x + Sublayer(Norm(x));  final Norm before the output head

RoPE in one picture

Split each Q/K head vector into pairs of dimensions; rotate pair i at position m by angle m · θ_i, with θ_i = base^(−2i/d). Then ⟨R(m)q, R(n)k⟩ depends only on (m − n) → relative position, applied in every layer and head, nothing added to the residual stream.

  • Many frequencies = many clock hands: fast hands resolve neighbors, slow hands track long range.
  • rope_theta (base): 10,000 originally; 500,000 in Llama 3 (supports 128K context).
  • Beyond trained length → unseen angle combinations → degradation. Extension: Position Interpolation (scale positions down, ~1K fine-tune steps), YaRN (frequency-aware scaling, far fewer tokens than earlier methods).

KV-cache per token per layer ∝ 2 × (KV heads) × head_dim. 405B: 128 → 8 KV heads = 16× smaller cache than full MHA. DeepSeek-V3's MLA instead caches a compressed latent per token (reported ~64× smaller than MHA at its dimensions).

Pitfall / war story

Textbook post-norm implementation scaled 12 → 48 layers: loss spikes then NaN after a few thousand steps; lower LR + longer warm-up only delayed it. Fix: pre-norm (norm inside the residual branch), RMSNorm, final norm before the head. Diagnostic habit: "where are the norms?"

5 interview questions

Q1. Why multi-head attention? Several independent lower-dimensional attentions, each with its own projections, capture different relations (coreference, syntax, adjacency) simultaneously, at roughly the FLOPs of one full-width head; outputs are concatenated and mixed by an output projection.

Q2. What's GQA and why does every modern model use it? Query heads share key/value heads in groups. It divides KV-cache memory (the main serving-memory cost) by the group size — e.g. 32 Q / 8 KV = 4× — with small quality loss vs MHA and much better quality than MQA. It can even be retrofitted to MHA checkpoints by uptraining with ~5% of original compute.

Q3. Pre-norm vs post-norm? Post-norm (original) normalizes after the residual add, so gradients pass through a norm at every layer and deep models need careful warm-up and can diverge. Pre-norm normalizes the sublayer input and leaves a clean identity path; well-behaved gradients at init, stable at 100+ layers. Needs a final norm before the output head.

Q4. How does RoPE work and how do you extend context? Rotate Q and K pairwise by position × frequency; their dot product then depends only on relative offset. Extension rescales the frequencies/positions (Position Interpolation, YaRN, larger base) so long distances map into trained angle ranges, usually plus a short long-document fine-tune.

Q5. Where do most parameters live, and why does it matter? In the feed-forward (SwiGLU) sublayers — roughly two-thirds in a dense model. That's why mixture-of-experts replaces exactly this sublayer with many experts plus a router: more parameters, same per-token compute.

Rooms read from the belt and add back to it, never replacing, which keeps a clean path for learning all the way down. On the left of every floor, the attention room: many desks, each with its own flags, labels, and buckets — multiple heads, each tracking a different relationship. Desks share filing cabinets of labels and buckets — grouped-query attention — to shrink the cache. Every flag and label wears clock dials rotated by position, so matches depend only on distance — rotary position encoding. On the right, the feed-forward room, where each tile thinks alone, holding most of the parameters, with a gated dimmer. At every door, a leveling gate — R M S norm, placed in the doorway, pre-norm — and one last gate on the roof.
